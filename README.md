# DailyFixer 🛠️

**DailyFixer** is a university group project developed as part of an undergraduate degree program. The project focuses on designing and implementing a practical, real-world web-based platform that helps users diagnose, manage, and resolve everyday technical and repair-related problems.

The system is built with an emphasis on clarity, structured design, and real-world usefulness rather than commercial deployment.

---

## 📘 Project Overview

DailyFixer is a centralized assistance platform that provides guidance and services for common issues related to:

- Home repairs
- Vehicles
- Computers and electronic devices
- Mobile phones

The platform combines **rule-based diagnostics**, **service coordination**, and **information access** to help users identify problems and find appropriate solutions efficiently.

---

## 👥 User Roles

DailyFixer supports multiple user roles, each with distinct responsibilities:

- **User** – Submits issues, follows diagnostics, and requests services
- **Admin** – Manages users, system data, and platform oversight
- **Technician** – Accepts and completes repair or service requests
- **Volunteer** – Provides free or community-based assistance
- **Store** – Lists spare parts and tools
- **Delivery Driver** – Handles item delivery between stores and users

---

## ⚙️ Core Features

- Rule-based diagnostic question flows (Yes/No decision trees)
- Technician booking and service request management
- Repair guides and instructional content
- Store listings for parts and tools
- Delivery coordination
- Rating and feedback system
- Admin dashboard with analytical reports and visual graphs

---

## 🧠 System Design Highlights

- Role-based access and dashboards
- Structured MVC-style architecture
- Database-driven design with full CRUD operations
- Focus on maintainability and scalability for academic evaluation

---

## 📊 Admin Dashboard Focus

The Admin Dashboard is designed to provide **high-level insights** using visual representations such as:

- User growth trends
- Service request distribution
- Technician activity levels
- Diagnostic success rates
- Store and delivery performance summaries

These reports are primarily graph-based to align with university assessment expectations.
